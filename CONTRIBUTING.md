# Contributing

Journal is a solo-maintained project. It isn't set up to accept outside pull
requests, issue triage, or feature discussions, and there's no guarantee that
issues or PRs opened here will be reviewed or merged.

## Using or modifying the code

You're welcome to download it, use it, and play with it. If you want to
change something, the standard GitHub workflow applies: fork the repository
and work from your fork.

```bash
git clone https://github.com/<your-username>/vscode-journal.git
cd vscode-journal
npm install
```

See [AGENTS.md](AGENTS.md) for the project structure, build/test commands,
and coding conventions, and [RELEASING.md](RELEASING.md) if you want to
package your own build.
